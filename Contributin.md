Contribution Guidelines. Welcome contributors.
Thank you for contributing to the centralized repository.
This documents outlines the guidelines for contributing to the LogisticShippingRates Project
Please follow the code style and conventions used in the existing code base. This helps maintain consistency across the project.
Ensure the your contributions are well documented. Include comment in you code where necessary. Provide a clear and consistent description of your changes in your pull request.
Before submitting a pull request make sure your changes have been tested thoroughly. Include relevant test cases and ensure that existing tests pass.
Check the issue tracker for any open issues or feature requests.
If you working on something, please comment the issue to let others know.
All contributions will go through a code review process. Be open to feedback and willing to make changes if necessary.
Code Reviews help maintain code quality and consitency.
Thank you for your contribution.
